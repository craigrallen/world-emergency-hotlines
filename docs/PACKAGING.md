# Capability packaging

This is a capability matrix, not a price plan or offer for sale. Public crisis access remains free and is never gated. No paid plan currently exists.

| Capability | Status | Boundary |
| --- | --- | --- |
| Public site and finder | Available now — public beta | Keyless static access; no uptime/support/SLA commitment. |
| Static downloads | Available now — public beta | Publicly accessible artifacts; reuse permission is separate. |
| Static API v1 | Available now — public beta | Versioned files and open CORS; no hosted query service. |
| Widget v1 | Available now — public beta | Client-side resolver and public demo. |
| Deterministic resolver | Available now — public beta | Local, explainable fallback over recorded data. |
| Metadata reports | Available now — public beta | Coverage metadata, not quality or availability scoring. |
| Issue intake | Available now — public beta | Public correction/provider issue templates; intake is a review lead, not guaranteed publication or response. |
| Tenant dashboards | Not currently offered | Requires future implementation and explicit agreement. |
| Hosted branded pages | Not currently offered | Requires future implementation and explicit agreement. |
| Webhooks or change feed | Not currently offered | Requires future implementation and explicit agreement. |
| Custom packs | Not currently offered | Requires future implementation and explicit agreement. |
| Uptime or support SLA | Not currently offered | Requires explicit future operational and written commitments. |
| DPA | Not currently offered | Requires legal review and explicit agreement. |
| Security attestations | Not currently offered | No certification or attestation is claimed. |
| Signed configs or domain allowlists | Not currently offered | Requires future implementation and explicit agreement. |
| Managed analytics | Not currently offered | Telemetry is not implemented; any future technical-health counters require the privacy contract plus qualified privacy/legal review. |
| Priority verification | Not currently offered | No verification or response SLA exists. |
| Payment processing (Stripe hosted Checkout) | Prepared, not enabled | Foundation service, contracts, and routes exist but fail closed; no price is published and no charge can occur until the activation checklist in `PAYMENTS.md`, including the licensing decision, is complete. |

The repository currently has no license. Public accessibility does not itself grant reuse rights, and this unresolved licensing decision blocks packaging or production-reuse commitments until permission and terms are explicitly established. Future capabilities also require implementation, safety/privacy review, and a written agreement; this matrix does not promise a roadmap or availability date.
