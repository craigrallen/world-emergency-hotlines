# Internal design-partner discovery and decision pack

Internal-only marker: `internal-design-partner-discovery-decision-pack-only/v1`.

This is deterministic, non-authoritative preparation only. It is not outreach, enrollment, a commercial offer, pricing, a contract, a paid commitment, billing, service activation, or an SLA/DPA/security/privacy/compliance/legal/availability assurance. It contains no telemetry or real user, provider, customer, organization, contact, personal, or crisis-case data. Public crisis information remains free.

`pack.json` binds its conservative capability matrix to exact raw bytes of a finite, immutable source-path inventory. The checked-in closed Draft 2020-12 schema and runtime verifier reject unknown fields, unsafe paths, source drift, duplicate file identities, incomplete inventories, unsupported assurance language, ambiguous outcomes, weakened boundaries, and demand-gate changes. The stable tracked-file reader is shared with the security/privacy evidence verifier.

The demand gate is deliberately narrow: do not recommend managed-service activation until at least three distinct credible organizations independently request the same clearly identified operational capability. General enthusiasm does not count. Proving that gate requires a separately authorized future evidence mechanism; this static, non-collecting repository slice has no such mechanism and reports the gate as held. The closed rubric retains `stop`, `hold`, and `continue` vocabulary, but this pack cannot emit or recommend `continue` or activation.

The repository currently has no license. Public access does not grant reuse permission, and permission and terms must be resolved before production reuse or packaging commitments.

The sole checked-in example is an exact const-bound, non-collecting scenario whose outcome is derived as `hold`. Every fixture field is closed: arbitrary organization names, contacts, email addresses, phone numbers, URLs, interview prose, and crisis data are rejected. Run `npm run test:design-partner-discovery` and `npm run verify:design-partner-discovery:dist` from `web/` after intentional review.
