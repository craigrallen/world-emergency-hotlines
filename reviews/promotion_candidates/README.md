# Promotion candidate review workflow

This directory holds explicit reviewer-facing artifacts for safe Phase 1 promotion into `hotlines.json`.

## Files

- `*.json`: promotion candidate bundles generated by `scripts/build_promotion_candidates.py`
- `*.approvals.json`: reviewer decisions consumed by `scripts/apply_promotion_candidates.py`

## Safety contract

- Candidate generation never writes to `hotlines.json`.
- Candidate actions are limited to safe additive actions:
  - `append_new_hotline`
  - `merge_missing_fields`
  - `upgrade_emergency_metadata`
- No destructive `replace_hotline` action exists.
- Canonical writes require both:
  - `--apply`
  - an approvals file via `--approvals`

## Approval file format

```json
{
  "decisions": [
    {
      "candidate_id": "ro-telefonulcopilului-merge_missing_fields-webverifieddirectoryv2previewjson-12",
      "state": "approved",
      "reviewer": "maintainer",
      "notes": "Reviewed against source artifact"
    },
    {
      "candidate_id": "ro-emergencymetadata-upgrade_emergency_metadata-webverifieddirectoryv2previewjson-11",
      "state": "needs_manual_source_check"
    }
  ]
}
```

Supported states:

- `approved`
- `rejected`
- `needs_manual_source_check`

## Example commands

```bash
python3 scripts/build_promotion_candidates.py \
  --canonical hotlines.json \
  --preview sources/web_verified_crisis_directory/web_verified_directory_v2_preview.json \
  --out reviews/promotion_candidates/2026-04-22-web-directory-candidates.json \
  --report REPORTS/promotion_candidates_20260422_web_directory.md

python3 scripts/apply_promotion_candidates.py \
  --canonical hotlines.json \
  --candidates reviews/promotion_candidates/2026-04-22-web-directory-candidates.json

python3 scripts/apply_promotion_candidates.py \
  --canonical hotlines.json \
  --candidates reviews/promotion_candidates/2026-04-22-web-directory-candidates.json \
  --approvals reviews/promotion_candidates/2026-04-22-web-directory-candidates.approvals.json \
  --apply
```
