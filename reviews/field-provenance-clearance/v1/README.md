# Internal field-provenance clearance ledger v1

`ledger.json` is the current repository-internal preparation template for qualified legal review. It exhaustively crosses the six provenance populations in the licensing legal-review handoff with nine explicit field groups. Its closed `field_inventory` assigns every observed scalar country/hotline field path in the byte-bound canonical `hotlines.json` exactly once to one group. Its closed `excluded_paths` separately enumerates structural containers and repository metadata with held, non-clearance wording; dynamic category-reference keys and the contributor array-item path are derived from the bound canonical data. Adding or removing an observed canonical field/path, deleting or duplicating an assignment, reassigning a path, or introducing an unexpected path fails runtime validation, while the Draft 2020-12 schema binds the exact declared inventories. Every population-by-group row remains held, asserts no permission, and has empty reviewer and legal-decision placeholders.

`example.synthetic.json` demonstrates the held entry contract using only `Synthetic Example Registry` and `registry.invalid`. Its closed synthetic evidence basis explicitly does not resolve to the real legal-review handoff. It is conspicuously synthetic and contains no hotline, provider, contact, customer, or crisis data.

Neither artifact selects a license, establishes ownership or permission, authorizes record changes, or may be exported or published. Run `npm run verify:field-provenance-clearance` from `web/`. The verifier checks purpose-specific closed schemas, exact canonical bytes, tracked no-follow reads, stable Git index/worktree bytes, the exact observed canonical field/path coverage and exclusions described above, real handoff source digests, purpose-appropriate evidence bindings, held-only invariants, `hotlines.json`, and production nonpublication. The nonpublication tuple scan uses a fixed-point decoder that stops on no change under strict eight-pass and 32 MiB bounds and handles percent encoding, JavaScript `\\xHH`/`\\uHHHH`, HTML entities, and nested mixtures of those forms. This bounded control does not claim to detect arbitrary encryption, compression, or paraphrase.
